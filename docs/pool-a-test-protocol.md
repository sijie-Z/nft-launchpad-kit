# Pool A — Agent Developer SDK Test Protocol（池 A 测试协议）

> Phase 1B 验证池 A：**agent 开发者是否愿意通过 SDK 使用发行能力**。
> 目标：陌生开发者从 `npm install` 到第一次成功发行 ≤10 分钟（中位数，无手把手帮助）。
> 本协议用于 Phase 1 第 2 周起的实测，由项目作者执行、按表登记。

---

## 0. 前置条件（测试开始前由作者准备好，不占测试者时间）

| 项 | 说明 | 状态 |
|----|------|------|
| 平台实例 | 已部署可访问的实例（Sepolia 测试网，baseUrl 可公开访问） | ☐ |
| 测试网钱包 | 已创建、有测试 ETH | ☐ |
| RPC | Sepolia RPC 可用 | ☐ |
| API key | `PLATFORM_API_KEY` 已配置并分发给测试者 | ☐ |
| SDK | `@nft-launchpad-kit/sdk` 已在 npm 发布 | ✅ 0.1.2 |
| 测试任务卡 | 发给测试者的"任务说明"（见第 2 节） | ☐ |

> ⚠️ 前置条件没齐不要开始测试 —— 那测的是环境，不是 SDK。

---

## 1. 招募（渠道与配比）

| 渠道 | 数量 | 说明 |
|------|------|------|
| 作者 agent 开发圈子 | 2 人 | 信任高，最先测 |
| AI/agent 社区（Discord/Telegram/Reddit） | 2 人 | **非同温层**，避免样本偏差 |
| 冷启动用户（GitHub/推特偶然看到） | 1 人 | 最真实的"陌生人" |

**配比原则**：至少 2 人来自作者圈子之外。

**邀请话术**：

> 我在做一个开源项目：让 AI agent 能自动发行 NFT/会员卡/凭证。我做了一个 SDK，想验证它好不好用。**测试环境已准备好**（测试网，不花真钱），你只需要按任务卡做一遍，大概 10 分钟。愿意试试吗？测试完告诉我卡在哪里就行。

---

## 4. 判定（池 A 停止条件）

| 结果 | 判定 |
|------|------|
| ≥2 人**无帮助**完成首次发行，且 median First Issuance ≤10 分钟 | ✅ SDK 验证通过，继续投入 |
| ≥2 人完成但 median >10 分钟 | ⚠️ 改进 onboarding/文档后复测 |
| 多人卡在同一 failure_stage | 🔧 优先修该环节（例：3 人卡 wallet → onboarding 问题） |
| <2 人愿意完成 | ❌ SDK 设计失败，回炉重设计 API |
